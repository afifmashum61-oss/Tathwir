# Tathwir - PerangkatAjar Pro 📚✨

**Official Subdomain Web**: [https://tathwir.idarah.my.id](https://tathwir.idarah.my.id)

**Tathwir (تطوير)** adalah Platform Generator Perangkat Pembelajaran AI interaktif untuk Guru Indonesia & Madrasah Kemenag. Aplikasi ini dirancang khusus untuk mempermudah penyusunan **Modul Ajar Deep Learning (Mindful, Meaningful, Joyful Learning)**, **Kurikulum Berbasis Cinta (KBC Kemenag)**, **Program Tahunan (PROTA)**, **Program Semester (PROSEM)**, serta **Rubrik Asesmen 3 Kolom**.

---

## 🌟 Fitur Utama

- 📖 **Modul Ajar Deep Learning & KBC (12 Halaman Standar Kemenag)**:
  - Cover Page & Header Box Resmi.
  - Identitas Modul & Kesiapan Peserta Didik (*Visual, Auditori, Kinestetik*).
  - Tema Kurikulum Berbasis Cinta (*Topik Panca Cinta & Materi Insersi*).
  - Karakteristik Materi & 8 Dimensi Profil Lulusan.
  - Desain Pembelajaran: Capaian Pembelajaran (CP) dengan tabel elemen & susunan gramatikal Arab.
  - Lintas Disiplin Ilmu, Tujuan Pembelajaran, & IKTP.
  - Kerangka Pembelajaran Deep Learning (*Mindful, Meaningful, Joyful*), Kemitraan, Lingkungan Belajar, & Pemanfaatan Digital.
  - Langkah-Langkah Pembelajaran Berdiferensiasi (*Pendahuluan, Inti, Penutup*).
  - Asesmen 3 Kolom (*Diagnostik, Formatif, Sumatif*).
  - Blok Tanda Tangan Resmi Kepala & Guru dengan penulisan gelar standar PUEBI/EYD.

- 📅 **Program Tahunan (PROTA)**:
  - Perencanaan alokasi Jam Pelajaran (JP) selama 1 tahun ajaran (Semester I & II).
  - Perhitungan otomatis Total JP Tahunan.
  - Cetak PDF & Export Word (.Docx).

- 🗓️ **Program Semester (PROSEM)**:
  - Matriks distribusi JP per minggu untuk Semester Ganjil (Juli-Desember) dan Semester Genap (Januari-Juni).
  - Perhitungan otomatis Total Alokasi JP Semester.
  - Cetak PDF & Export Word (.Docx).

- 🍔 **Hamburger Menu Responsive**:
  - Navigasi dropdown rapi, bersih, dan responsif di berbagai ukuran layar.

- 📄 **Dual Export (PDF & Word .Docx 1-to-1 Parity)**:
  - Export PDF presisi dengan isolasi Halaman Sampul (Cover Page di Halaman 1, Isi Modul mulai Halaman 2).
  - Export Word (.Docx) menyertakan seluruh 12 halaman/bagian Modul Ajar, PROTA, dan PROSEM.

## 🚀 Cara Menjalankan Project

### Prasyarat
- Node.js versi 18+ atau yang lebih baru.
- npm / yarn / pnpm.

### Langkah Instalasi

1. Clone repositori ini:
   ```bash
   git clone https://github.com/afifmashum61-oss/Tathwir.git
   cd Tathwir
   ```

2. Install dependensi:
   ```bash
   npm install
   ```

3. Jalankan server pengembangan (Dev Server):
   ```bash
   npm run dev
   ```

4. Buka di browser:
   `http://localhost:5173`
